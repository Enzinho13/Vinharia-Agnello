# Vinheria Agnello - Check-Point Front-End / Web Development

## Descrição do Projeto
A Vinheria Agnello é um e-commerce e portal informativo desenvolvido para apresentar os rótulos de vinhos finos, dicas de harmonização e a tradição da marca. O site foi desenvolvido em HTML5 semântico, CSS3 e JavaScript puro, contando com navegação responsiva, multimídia embutida e design temático em tons vinho e dourado.

**Atualização do Checkpoint:** O projeto agora inclui um **Sistema Básico de Gerenciamento de Vinhos**, permitindo o cadastro simulado de novos rótulos através de uma área administrativa protegida.

## Link do site Publicado (GitHub Pages)
Acesse o site: [https://enzinho13.github.io/Vinharia-Agnello](https://enzinho13.github.io/Vinharia-Agnello)

## Como testar o Sistema de Gerenciamento (Área Admin)
Para avaliar os requisitos solicitados em JavaScript (`prompt()`, `alert()` e `console.log()`):
1. Acesse o site publicado pelo link acima.
2. Na barra de navegação superior da **pagina de vinhos**, clique na opção **"Admin"**.
3. Na caixinha interativa que se abrirá, digite a senha de acesso: **`100807`** e clique em "Entrar".
4. Siga as instruções dos *prompts* na tela para simular o cadastro de um novo vinho.
5. Pressione `F12` (ou clique com o botão direito -> Inspecionar) e vá até a aba **Console** para visualizar os dados organizados.

## Estrutura do Projeto e Páginas
O projeto conta com 5 páginas HTML funcionais organizadas na seguinte estrutura:

## Páginas do Projeto

| Arquivo | Descrição |
| :--- | :--- |
| **index.html** | Página principal com o vídeo institucional e banner de destaque |
| **src/pages/historia.html** | Trajetória, valores e história da Vinheria Agnello |
| **src/pages/vinhos.html** | Catálogo com os rótulos, preços e botão de compra |
| **src/pages/dicas.html** | Dicas de harmonização e tabela de temperaturas de serviço |
| **src/pages/contato.html** | Formulário de mensagem com nome, e-mail e telefone |

## Tecnologias e Recursos Utilizados
- **HTML5 Semântico:** Utilização de `header`, `nav`, `main`, `footer`, `section`, `article`, `table` e `form`.
- **CSS3:** Customização com variáveis, Flexbox, layout interativo (dropdowns), responsividade e contraste otimizado.
- **JavaScript:** 
  - Sistema de autenticação simples para a área do gerente.
  - Interação de entrada de dados com `prompt()` e avisos via `alert()`.
  - Estruturação e exibição de dados formatados via `console.log()`.
  - `localStorage` para validação de maioridade e manipulação do DOM.
- **Multimídia e Iframe:** Vídeo institucional do YouTube e fotos em alta definição em todas as páginas.
